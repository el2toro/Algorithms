# Algorithms

Here are implemented the following algorithms with their running time expresed in O or big O notation:

##
> - ### Breadth-first search BFS
The running time of the BFS is: **O(V + E)**, where **V** is the number of **vertex** and **E** is the number of edges.

##
> - ### Deep-firs search DFS
The running time of the DFS is: **O(V + E)**, where **V** is the number of **vertex** and **E** is the number of edges. 

Time	O(V + E)	Each vertex and edge is processed once

Space	O(V + E)	For visited set + recursion stack + adjacency list
